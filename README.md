# Project 008: Multiplication Table

## Description
This project prints the multiplication table (1 to 10).  
It helps beginners learn how nested loops work.

## Skills Learned
- For loops  
- Nested loops  
- Basic printing  
- Formatting output

## How to Run
1. Open `multiplication_table.ipynb` in Jupyter Notebook.
2. Run the cells to generate the full multiplication table.
